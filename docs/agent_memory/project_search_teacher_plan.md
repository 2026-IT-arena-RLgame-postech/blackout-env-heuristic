Distillation hit the teacher ceiling (D9: teacher anyangle loses to student P5a −29.5). User approved (2026-10-02) a sequential, validated track, documented in docs/experiments_index_ko.md "탐색 교사 계열":
S1 V(s) value net from existing shards → S2 exact-rules numba simulator (+S0 record opponent actions) → S3 1-ply macro-option search teacher with V at leaves → S4 deeper search (best-first/MCTS, opponent options) + distill.
Design defaults (my recommendation, user said proceed): hand-written sim at behavioural precision (float64, sample hidden RNG), macro actions = per-unit target/role options, opponent model = student P5a + heuristic samples, search only at decision points, labels offline.
User wanted world-model design refined together before building; this plan was the result. Related: [[project-distill-next-steps]].

**Why:** a stronger teacher is the only lever left inside distillation; RL fine-tune uncertain.
**How to apply:** validate each stage before the next; report stage metrics; keep using paired held-out evals vs P10 (best since 2026-10-02; P5a before).
