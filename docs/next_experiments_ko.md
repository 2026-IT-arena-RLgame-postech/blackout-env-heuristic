## 3. 증류(학생) 쪽

- **같은 교사로 미세 증류 반복은 수익이 줄어든다(§57)**: P20 → P21e → P22 → P23a(+3.6, 잡음 안). 다음 학생은 **더 강한 교사나 새 정보**가 필요하다.
- **탐색을 교사로**: 1번 관문이 통과하면 P24c + 탐색의 행동을 라벨로 증류(분기 Q 증류, §22 C는 탐색 이득의 ~20% 추정, 보류 중이었음).
- **기억 있는 학생(KDA, `docs/kda_temporal_design_ko.md`, `model/modules/kda.py`)**: 상태가 있는 교사(V32.1 래치, V4·V17·V19 18–32% 이력 의존)를 그대로 배우게. 상대 식별 프로브에서 GRU/KDA가 10초에 0.62(무상태 0.40). 사용자 결정(2026-09-30): 경기마다 기억 초기화, 추론 지연 허용.
- **상대 조건부 교사**: 상대 유형에 따라 다른 휴리스틱을 쓰는 교사 + 기억 있는 학생 또는 학생 혼합(§ 요약 "다음 계획" (4)). OOD1 결과로는 h4가 순환 상성이 아니어서 우선순위는 낮아졌다.
- **D6(및 섭동 D6)를 상대 풀에** — 강한 신경망 상대 강건성(승인된 백로그).
- **합성 상태로 OOD 보강**: 실제 샤드 상태의 구조적 섭동 → 기억 없는 교사로 라벨(사용자 아이디어, 2026-09 백로그).

## 4. 휴리스틱 쪽 (보류 해제 시)

- **상대 따라 변하는 쓸기 연구 계속**(사용자 요청 2026-10-07): V32.1의 `adapt_k` 래치를 일반화 — 경기 후반 상대 판별 후 쓸기·경비 강도 조절. 목표: 강한 상대 이득 유지 + 약한 상대 점수차 손실 최소.
- **임의 각도 V21 목표 선택을 직선(임의 각도) 거리장으로** — 교사 상한 상승(승인된 백로그; 이동은 이미 거의 최적, 목표 선택만 8방향).
- **P24c/탐색이 찾은 수를 규칙으로**(자율 개선 루프의 "rule-ize" 단계, 보류 중): 탐색 이득이 큰 구간(2차 경주, Carrier 이탈 등)을 분석해 V33 후보로.

## 5. 탐색 쪽

- **0–5초 손해 재측정(Q5)** — 새 롤아웃 망(r22/r24c)으로 롤아웃–실제 어긋남이 줄었는지(미승인 후보).
- **잎 가치(V) 재적합** — 지금은 옛 `s2v_f3xd2 iter2`. 이전 재적합은 이득 없음(R2), 학생이 크게 바뀐 지금(P24c) 다시 볼 만함.
- **탐색 가속** — 남은 병목은 CPU 잎 단계(B1 §52, QZ §53). GPU 시뮬 이식은 GPU가 희소해 보류.
- **o4f 상대 풀 갱신 규칙** — 경기 중 상대 확률 갱신(상대 모델이 h4·V32 유형을 보도록).

## 6. 평가·도구

- **Elo-24 확장**: 새 챔피언·탐색 정책 추가 시 `examples/elo24_config.json`에 넣고 `examples/elo24.py run --stage 1/2`로 이어 돌리기(바뀐 정책의 쌍만 자동 보충). 그림 양식은 기존 토너먼트 양식 유지(RdYlGn 히트맵 + n/SE, Elo 95% 구간 점 그래프, LOO 진단).
- **Unity Elo**: 상위 5–6개만 Unity로 승률 행렬(시뮬과의 차이 확인).
- **채택 규칙 정리**: 단계 관문(64 → 256 → 1024), 3 SE 채택 / 1 SE 미만 기각, OOD 규칙(§56.6), 약한 상대 승률 규칙(§58.6)을 한 문서로.
